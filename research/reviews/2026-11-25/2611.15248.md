CORE: PLAW-EM2d is a two-dimensional Vlasov-Maxwell code for laser-plasma instabilities. It uses a hybrid electrostatic-TEz field split, an Eulerian 2d2v electron solver, and a cold closure for the out-of-plane response. Vacuum propagation, Landau damping, and a homogeneous-plasma comparison with PIC benchmark the solver. In an inhomogeneous plasma the code reproduces convective stimulated Raman backscatter with a reflectivity the abstract says is consistent with the Rosenbluth estimate. In a transversely extended target it captures SRS side scattering, resolving oblique electromagnetic and Langmuir waves that satisfy the resonance conditions.
