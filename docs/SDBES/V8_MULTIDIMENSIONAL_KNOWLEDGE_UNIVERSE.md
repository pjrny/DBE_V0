# SDBES V8 — Multidimensional Knowledge Universe (visual first release)

**Status:** Implemented frontend visualization increment, read-only. This is **not** a completed scientific simulation, V2 universal probability engine, graph of verified cross-field causal pathways, or V9 campaign operator.

## Restored original mission

SDBES is the **Search for Dimensions Beyond Energy Scarcity**. Its task is to help humans understand all six research domains and their relationships, including demand reduction and discovery acceleration, not to optimize only the DBE/DBE-S fusion program. The focused Observatory is a research input, not the framework's taxonomy.

This increment extends—not replaces—V1–V7. The existing evidence inspector, 90-candidate atlas, 10 reviewed claim-to-concept records, 13 specialized Observatory claims and V7 source-integrity findings remain available. The new default visual projection is the **Knowledge Universe**; the prior **Record table** is preserved through a view switch.

## Six linked visualization lenses

1. **Universe:** deterministic two-dimensional layout of the original six domains and all 90 Phase-1 discovery candidates. Clicking nodes or domain groups updates the existing inspector. Inter-domain distances are layout choices, not scientific differences. Taxonomy-membership spokes are hidden by default because 90 visible edges add clutter; when shown they mean `PART_OF_DOMAIN`, nothing more. Search and class filters dim nonmatching nodes and warn that adverse or null evidence may be hidden.
2. **Evidence:** the original V1 `Formal / Empirical / Applied × Validated / Independently checked / Generalized` matrix. The currently staged reviewed-case records have method tags but **no canonical V/I/G assessment-cell receipts**, so all nine cells explicitly show `UNKNOWN`. Related reviewed-case method tags are displayed outside the matrix, never promoted to verification. Support and challenge remain distinct in the existing inspector.
3. **Dependencies:** displays only the actual reviewed V5 links such as `COMPONENT_EVIDENCE_FOR` and `MECHANISM_SEED_FOR`. These are evidence/application relations, **not** V3 structural prerequisites. No evaluated V3 structural gate is currently registered in this projection; the lens clearly says so and shows `ALL`, `ANY`, `k-of-n`, and four-valued knowledge semantics as a legend, not fabricated graph nodes.
4. **Dynamics:** illustrates V4 state variables, control, disturbances and observation semantics without fabricated trajectories. Physical state `x(t)` and scientific knowledge `K(t)` are separate. The **Run scenario** control stays disabled until a real pinned, bounded domain model with a use-authorization receipt is available. V4 itself is not disabled.
5. **Time and revision:** an ordered snapshot chronology of atlas intake, Observatory and workbench, not a physical progress or credibility time series. Claim-level change playback requires later versioned assessment diffs.
6. **Exploration:** shows optional cross-domain *shared catalog-tag candidates*. They are expressly labeled `CATALOG_TAG_OVERLAP_ONLY`; never added to reviewed scientific relationship edges or assigned a causal sign, validity, likelihood, or priority. The existing exploratory research queue is preserved separately.

## Data and mathematical invariants

- Six original source domains A–F, all 90 stable IDs, and exact original discovery metadata remain intact.
- A concept is not a claim, an evidence object, a structural predicate, a capability, a model, or a publication.
- Paper/source count is not scientific confidence. A research card association is not evidence-strength promotion.
- Formal proof validity, empirical validity, applicable regime and engineering implementation are separate dimensions.
- V3 graph centrality, path count, matrix powers, eigenvectors and candidate tag overlaps are not general causal effect or truth estimators. No universal centrality score is computed here.
- Node size is fixed for all discovery candidates; hue encodes **domain only** with explicit textual label. Selected-node rings encode selection only; layout proximity has no domain meaning.
- Status, polarity, method, evidence quality, incompatibility, and research-work priority remain independent fields.
- Every visual output and session export should be reproducible from frozen source snapshots and the selected lens/filters. Versioned geometry is deterministic by ID.
- A later V8 mathematical diagnostics layer may display eigenmodes or matrix projections only with a declared matrix, operator, normalization, snapshot and interpretation; absent those inputs, no output is fabricated.

## Design and accessibility

- Consistent visual vocabulary with the existing workbench; six top-level lens tabs within the main visualization column.
- 2D map is the default, with `Show all domains` and click-to-focus for each of the six source sectors.
- Every concept is also reachable using a keyboard/touch list within its selected domain, and SVG nodes have descriptive accessible labels and Enter/Space activation.
- Responsive rules keep the inspector below the map on narrow screens; no reliance on a 3D rendering capability to use the product.
- Filtering never deletes or rewrites underlying records. When filters are active, a caution remains visible.
- The old searchable record table remains available. V7 Observatory counts and program claim load remain outside the general-domain map.

## Initial acceptance checks

- Six domains with the source inventory counts `A=18, B=13, C=17, D=15, E=15, F=12`.
- Exactly 90 distinct concept nodes and stable deterministic layout geometry across reloads.
- Changing selection and filtering changes navigation, not evidence status.
- No derived cross-domain tag overlap becomes a typed dependency or causal link.
- V/I/G matrix cells remain UNKNOWN until actual structured assessments are available.
- No run button or result shown for an unregistered V4 model.
- Historical V5 record inspector and V7 Observatory scale findings remain navigable.

**Design rule:** Preserve information first. Aggregate second. Simulate last.
